# IT Мамандықтар каталогы (Зертханалық жұмыс)

Бұл жоба IT мамандықтар каталогын көрсетеді және курсқа жазылу өтінімдерін Flask сервері арқылы SQLite базасына сақтайды.

## Технологиялар:
* **Frontend:** HTML5, CSS3
* **Backend:** Python (Flask)
* **Database:** SQLite (`my_database.db`)
* **GUI tool:** DBeaver

## Жобаны жергілікті (Local) іске қосу:
1. Репозиторийді жүктеп алыңыз.
2. `app.py` файлын іске қосыңыз:
   ```bash
   python app.py
